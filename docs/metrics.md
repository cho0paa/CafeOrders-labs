# Метрики модуля Legacy/LegacyBillProcessor.cs

## До рефакторингу

Спосіб вимірювання: цикломатична складність — вручну (1 + кожен `if`, `else if`, цикл, `&&`, `||`) і
звірено з аналізатором CA1502 (тимчасовий поріг 1); LOC — рядки тіла методу без порожніх;
глибина — кількість вкладених блоків, тіло методу = 1.

Розрахунок CC методу `Handle`:

| Точка розгалуження | Кількість |
| :--- | :--- |
| `if (items != null)` | 1 |
| `if (items.Count > 0)` | 1 |
| `if (state == "new" \|\| state == "paid")` і оператор `\|\|` | 2 |
| `if (clientMail != null && ...)` і оператор `&&` | 2 |
| два цикли `for` | 2 |
| три перевірки виду гостя (`if` / `else if` / `else if`) | 3 |
| три перевірки межі знижки `if (> 500m)` | 3 |
| `if (сума < 1000m)` | 1 |
| `if (sendMail)` | 1 |
| Разом точок розгалуження | 16 |

CC = 1 + 16 = **17** (CA1502 показав 17).

| Метод | LOC | CC (вручну / CA1502) | Глибина вкладеності | Параметрів |
| :--- | :--- | :--- | :--- | :--- |

| `Preview` | 25 | 9 / 9 | 2 | 3 |
| `DescribeClient` | 8 | 3 / 3 | 1 | 1 |
| `DumpLog` | 4 | 2 / 2 | 1 | 0 |
| Клас загалом | 135 | 31 (сума) | — | — |

Додатково:

- відповідальностей класу — 6: перевірка входу, сума рядків, знижка за видом гостя, доставка,
  форматування звіту, журнал подій;
- дубльованих рядків між `Handle` і `Preview` — 14 (сума, три гілки знижки зі стелею, доставка);
- магічних чисел — 7 різних (`0.15m`, `0.30m`, `0.05m`, `500m`, `1000m`, `60m`, `10`), 17 входжень.
